# Apple iPhone 18 Pro：当前页面的设计与交互

## 触发、视觉响应与用途

- 进入 → 官方产品 MP4 在黑色全宽舞台登场；重播只重放这段，不代替影片。

- Highlights 进入视口 → 圆角摄影图像和进度控件随之出现，五项图库自动推进；手动选择/暂停/最后重播 → 按相机、续航、颜色、性能、Siri 依次展示产品重点。

- Design 点击七项胶囊 → 同一舞台内展开左侧说明卡，说明卡替换当前胶囊、其他胶囊下移、右侧摄影变化；卡内前后切换与关闭均可逆；Colors 的四个色点联动真实摄影。

- 在镜头长段内向下/向上滚动 → 暂停的官方相机 WebM 按进度 seek，标题让出画面；后续性能和续航部分用官方静帧保留 sticky 媒体及其与前后文的交接。

- 景深四选项 → 官方 f/1.48、1.8、2.8、4.0 摄影交叉变化；旧机型 select 更新比较对象；横向摄影区保留原生滑动。

- Watch the film → 黑色全屏影片层与原片有声控件；Explore 导航、亮点暂停与手机重排支持正常滚动/键盘。

## 完整浏览路径

首屏 → Highlights → Design viewer → 相机滚动段 → 景深比较 → 横向摄影区 → 性能 → 续航 → 机型比较 → 浅色共享功能/购物/材料架子 → 说明与页尾。页面内容比原页少，保留主要交互类型和后段明暗交接。

## 主题与声音

产品摄影章节固定黑/深灰；比较、购物和环境等后段切成浅色。没有全局深浅切换。

首屏和滚动视频静音；Watch the film 点击打开官方 HLS 影片，172.38 秒，用户触发播放后有声音，可静音、调音量和全屏；关闭即暂停。静音摄影先突出材质与镜头重点，点击影片后才加入音乐和讲解，避免读页时自动发声。

## 配色、排版与元素协调

主题与动效配合官方摄影和影片突出硬件，通过细节卡的展开/收起、图库进度、景深比较及滚动媒体/文字交接组织产品展示。

## 观察依据

匿名浏览器实测了七项 viewer 中 Colors 卡的 inline 展开与原站影片层；源影片 muted=false，首屏其他媒体 muted=true。源公共组件包含 StaggeredFadeIn、ProductViewer 与 VideoScrub。源页处于 no-enhanced 分支，相机增强滚动视频的实时播放未验证。
