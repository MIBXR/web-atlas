## 综合教学框架

本库把网页分成以下三层，可以帮助非专业使用者逐步观察：

1. **视觉材料：你能拿来做设计的东西。** 色彩；字体与排版细节；形状与线条；图像与图标；空间；质感。空间不是“剩下的空白”，而是可主动分配的材料。质感包含光影、颗粒、渐变和表面感，也可以选择完全不用。
2. **组织原则：这些材料如何形成关系。** 布局与对齐；层级与对比；比例与平衡；重复、节奏与一致性。比如同一种按钮始终使用同一形状，相关标题与正文距离较近，不同章节距离更大。
3. **网页体验：这些关系是否服务用户。** 先明确目标和内容顺序；操作后反馈状态；在不同屏幕、键盘与阅读需求下仍然可用。

“协调统一”不要求所有元素都一样。重点内容需要有足够区别，基础规则则应能重复使用。先建立字体、颜色角色、圆角/线条和间距的共同规则，再决定哪里要打破规则来突出重点。

## 本地协调实验

设计实验室入口：[lab.html](../lab.html)。同一虚构产品“拾光笔记”保留名称、卖点、功能和行动内容，采用三种原创协调方案：

- **纸页：** 温暖纸白、深墨与陶土强调色；衬线标题；细边框、小圆角；疏朗留白。把重点放在阅读和安静记录。
- **亲和：** 浅绿色、深绿与莓色强调；圆润感无衬线；大圆角、柔和阴影；中等密度。把重点放在轻松上手。
- **工具：** 深蓝、亮文字与青色强调；等宽字体；直边、清晰轮廓；紧凑间距。把重点放在直接、可扫描的信息。

完整方案同时改变配色、字体、形状、留白，并配合图形、质感与反馈。单项实验可以只借用另一方案中的一项，所有产品文案保持不变。页面会说明本次实际改了什么，并提出观察问题：重点是否仍明显、字与形是否表达类似气质、距离是否形成可理解的分组。

实验室还提供实时颜色角色选择、字体选择、三种图文布局、留白范围、圆角选择、三种原创SVG呈现、标题层级对照、平面/颗粒/阴影质感与微动效开关。关闭动效或开启减少动态偏好时，操作反馈按钮仍显示结果文字。两组色彩对比读数对应所选纯色组合。系统字体可能因操作系统而略有变化，不使用CDN。

同一内容示例可带入本地`data/cases.js`中的38条案例风格，也可由`?style=<id>`指定。色板来自条目；字体、布局、形状、间距、图形等按ID/类别归纳为教学配置，页面会说明这些教学配置的迁移边界。38 个独立 Demo 展示各自的来源构成。主题实验保留参考、系统、浅色和深色选择，按背景、表面、正文与强调角色一起解析色板，原始图像不反色。当前配置可复制为JSON，并附到通用Prompt；浏览器不允许自动复制时提供可选文本。

## 基础Prompt的使用方法

先填写产品、用户和目标，再选择一种主要视觉方向。要求模型给出颜色角色、字体层级、线条/形状与间距规则，解释这些规则如何共同突出核心行动。选择本库真实案例作为具体风格证据，不只写“高级、有设计感”。实现后用手机、键盘、状态反馈和实际内容检验，不以样张好看代替验证。

设计实验室提供可复制的完整基础Prompt及手动复制后备方式。使用时还需叠加所选风格的具体约束；该Prompt不预设哪一种风格最好。


## 设计元素怎样统一表达

| 元素 | 在画面中的作用 | 实验室中的操作 |
|---|---|---|
| 配色 | 区分背景、表面、正文、强调和反馈 | 带入案例色板、改色、比较纯色文字对比度 |
| 字体与排版 | 形成语气、阅读节奏和尺度层级 | 切换字型、布局、层级与留白 |
| 图像与图形 | 展示产品、人物、世界或作品 | 改变图形类型、比例及质感 |
| 形状与构成 | 把按钮、容器、装饰组织成一致语言 | 改变圆角／几何形状和组合 |
| 深浅主题 | 保持背景、表面、正文与强调的协调 | 参考／系统／浅色／深色切换与配置导出 |
| 动效与反馈 | 解释状态变化、引导注意、保持空间连续 | 切换动效、触发反馈，并比较静态状态 |
| 协调关系 | 让所有元素围绕同一主题和重点 | 单项混搭、加载案例方案、复制配置与 Prompt |

理论来源见本文的第一方来源表。文字对比度读数覆盖所选纯色组合。地区记录具体机构与创作来源。
