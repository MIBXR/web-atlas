— 个案例— 条设计巧思固定 Git 版本

01 / SKILL

先探索，再围绕需求选方向

skill 提供选型工作流与获取脚本，完整案例保存在 Web Atlas。新任务读取最新目录，讨论和取材使用同一版本。可以先问“有哪些案例”。

查看 skill 与获取脚本

安装 skill 后，可以这样开始

$web-atlas 我还没决定网站的设计方向，先介绍有哪些案例。
接下来根据我的产品、用户和页面任务，和我一起筛选几个候选。
确定方向后，自动读取完整说明、文档和源码，再完成实现。
也可以单独探索设计巧思：给我一个清晰的页面基础，
再选择来自不同案例的悬停反馈和滚动叙事，说明各自职责与组合约束。

DESIGN PATTERNS

按机制取材，跨案例组合

按视觉、微动效、页面动效、声音、内容与组织筛选可独立迁移的机制；还可结合功能用途和来源案例继续筛选。每条巧思保留触发、效果、约束和来源。skill 的 pattern-search、pattern-show 与 pattern-export 使用同一会话版本，pattern-search --type page-motion 可筛选页面动效，自动取得来源案例与源码。先分配基础、辅助和强调的职责，再检查动效与输入冲突。

浏览设计巧思 查看巧思索引 JSON

02 / RETRIEVE

探索案例，也可以直接取材

查看结构化索引 JSON

搜索品牌、布局、场景或交互关键词。“案例包”是 JSON 文件，包含完整设计资料、网页右侧说明、文档原文，以及源码和媒体的文件路径。已经选好案例时，可以直接复制入口。

03 / LOCAL WORKFLOW

仓库里也能直接运行

使用 Node.js 即可运行，无需安装依赖。完整导出保留 Demo、共用模块、字体和媒体的相对路径；大型品牌案例可能包含影片。

读取完整工作流与数据契约
node scripts/atlas.mjs search "深色 产品" --limit 3
node scripts/atlas.mjs show linear-workflow
node scripts/atlas.mjs show linear-workflow --source
node scripts/atlas.mjs export linear-workflow --out ../linear-reference

DESIGN WITH CONTEXT

带着依据适配你的场景

保留设计机制
读取布局、视觉层级、状态和触发关系，选择能说明当前产品的表达方式。

替换真实内容
用自己的品牌、文案和有使用权的素材，依据真实功能调整交互。

验证当前成果
检查桌面与手机、键盘、减少动态和资源加载，保留来源中近似与未验证的标记。

SOURCE-BACKED / SCHEMA 1

取得组件与内容素材

在素材库操作代表性样例，再让 Skill 读取使用说明、版本、许可证与完整 Demo。案例、巧思和素材共用同一取材会话。

python ATLAS_SCRIPT --session SESSION_FILE material-search "渐变"
python ATLAS_SCRIPT --session SESSION_FILE material-show shaders --source
python ATLAS_SCRIPT --session SESSION_FILE material-export shaders --out NEW_DIRECTORY

直接读取 素材目录，或下载 Shaders 资料包。更多组件与作者预设请到来源查看；浏览器不支持 WebGPU 时，Demo 显示明确标注的静态参考。
