# Arc UI 官网首页 · 复刻对照

## 范围与条件

原站为 [uiarc.dev](https://uiarc.dev/)，采集日期为 2026-11-01，范围是完整英文首页：公告、导航、首屏、客户标识、两组产品媒体、安装入口、价格、FAQ、最终行动及页脚。目录、文档、Showcase、Pro、账号与交易保留原站链接。

原站与本地使用同一 Chromium 浏览器，CSS 视口为桌面 **1440×1000**、手机 **390×844**，DPR 为 1，浅色主题、首屏滚动位置为 0。桌面同尺寸截图并排查看；手机截图保留相同浏览器采样尺度并排查看。截图来自实际浏览器，页面没有加载整站截图。桌面原站画面保存在 `previews/cases/uiarc-platform-reference.jpg`，本地预览和手机预览在同目录。

故障前已观察完整首页及原站的明暗主题、手机菜单、年度／免费价格状态。后续重新载入原站出现 `ERR_CONNECTION_CLOSED`，因此未将未完成的源端动态复核标为通过；已保存截图、DOM 和发布样式仍用于本次静态对照。

## 保留与差异

- 官网只有发布产物，未取得独立网站工程。本地重新编写 HTML、CSS 和交互，`source/site-styles/` 仅作为布局、断点与时序的溯源资料。
- 品牌文案、13 个客户标识、15 组媒体和两款字体保留原内容。媒体的比例、原字节与许可入口由素材清单记录。
- 价格中的滚动数字、Radix 手机菜单和 FAQ 内部动画没有复用官网运行代码；页面静态与状态关系作为参考，动态差异如上表所列。
- 本地不接入统计、实时 GitHub 星数、账户、购买和支付。价格按钮通往官方价格页；原站交易弹层和登录流程不在复刻范围内。
- 未完成慢网络、冷缓存失败恢复、真实触屏、其他浏览器与原站全部过渡的逐帧复核。
